# 世界史 復習アプリ

忘れかけたころに一問一答を出題してくれる、自分用の復習アプリ。

- HTML / CSS / JavaScript だけで動く1ページのアプリ（GitHub Pages で公開）
- 問題と復習記録は、別の**非公開**リポジトリに JSON で保存する
- GitHub のトークンはアプリの設定画面で入力し、端末の中にだけ保存する（このリポジトリには入れない）

## できること
- **問題**：章・地域・時代で範囲を選んでランダム出題。○×のあとに「毎日の復習に送る／送らない」を選べる
- **復習**：問題で送ったものを間隔反復で、忘れかけたころに出題。好きな範囲を何周もする「練習」も
- **年号**：並び替え（古い順）／年号4択／年号入力／出来事4択。地域・時代・タグで範囲をしぼれる
- **章ごと**：教科書の流れに沿った全24章のまとめノートと一問一答（1400問、地域・時代つき）。全問が最初から「問題」に入っている
- **ノート**：出来事を地域ごと・年代（世紀）ごと・年表で見られる。区切りごとに自分のまとめを書ける
- **事典**：関係マップ（前後の出来事・人物・国を線でつなぐ）と因果の流れ（なぜ起きた？→どうなった？を矢印と理由つきで）。出来事（原因・背景／結果・影響／関連人物・国・事項）、人物（何をしたか・関わった出来事）、国（国ごとの流れ・関わる出来事・人物）を、全24章ぶん収録。文中の項目名はリンクになり、たどって読める。直す・メモ・自分で項目を追加もできる
- **関連表示**：出来事ごとに、関連づけた出来事・同じ地域の前後の流れ・同じころのほかの地域・関連する一問一答を表示
- **追加**：一問一答、年号つきの出来事、Claude に作ってもらったものの貼り付け、基本の年号セット

## ファイル
- `index.html` … 画面
- `app.js` … 動き（間隔反復・年号ドリル・ノート・同期・バックアップ）
- `starter.js` … 基本の年号セット（Claude 作成。教科書で確認して使う）
- `chapters.js` … 章別のまとめと一問一答（Claude 作成。教科書で確認して使う）
- `jiten.js` … 事典（出来事・人物・国。Claude 作成。教科書で確認して使う）
- `sw.js` … オフラインでも開けるようにする仕組み
- `manifest.json`・`icon-*.png` … ホーム画面に追加したときの名前とアイコン
