# 世界史 復習アプリ

忘れかけたころに一問一答を出題してくれる、自分用の復習アプリ。

- HTML / CSS / JavaScript だけで動く1ページのアプリ（GitHub Pages で公開）
- 問題と復習記録は、別の**非公開**リポジトリに JSON で保存する
- GitHub のトークンはアプリの設定画面で入力し、端末の中にだけ保存する（このリポジトリには入れない）

## ファイル
- `index.html` … 画面
- `app.js` … 動き（間隔反復・同期・バックアップ）
- `sw.js` … オフラインでも開けるようにする仕組み
- `manifest.json`・`icon-*.png` … ホーム画面に追加したときの名前とアイコン
